# 🥕 2 B Continued | Carrot Market Clone Coding

> **이스트소프트 오르미 프론트엔드 15기 2조 '2 B Continued'의 당근마켓 클론 코딩 프로젝트입니다.**

빌드 도구 없이 **HTML · CSS · Vanilla JavaScript(ES Module)** 만으로,
회원가입부터 매물 등록 · 검색 · 실시간성 채팅 · 매너 평가 · GPS 동네 인증까지
하나의 흐름으로 동작하는 중고거래 서비스를 구현했습니다.

- **작업 기간:** 2026.08.13 ~ 2026.08.21
- **배포 주소:** [배포 url](https://carrot-2-b-continued.vercel.app/pages/home/)

## ✨ 주요 기능

### 회원 · 인증

- 이메일 회원가입 / 로그인 / 로그아웃, JWT 기반 인증
- 내 정보 조회 및 닉네임 · 동네 수정, **매너온도 시각화**(온도 · 이모지 · 게이지 색상)
- 로그인 상태에 따라 헤더 메뉴가 자동으로 전환되고, 비로그인 상태로 보호 페이지 접근 시 로그인 페이지로 안내

### 지역 선택 (공통 모듈)

- **시/도 → 시/군/구 → 읍/면/동 3단 연동 select**
- 회원가입 · 내 정보 두 화면이 같은 모듈을 사용하며, 저장된 지역 코드로 3단 값 자동 복원

### 중고거래

- 홈 최신 매물 / 전체 매물 그리드 / **키워드 검색 + 페이지네이션**
- 매물 상세 — 이미지 · 판매자 · 가격 · 조회수 · 채팅수 · 거래 희망 장소
- 매물 **등록 · 수정 · 삭제** — 사진 1장 업로드, 가격 천 단위 콤마 자동 입력, 필수값 검증
- **내가 쓴 글일 때만** 수정 · 삭제 버튼이 보이고, 남의 글에서는 채팅하기 버튼이 보임

### 채팅

- 채팅방 목록(마지막 메시지 · 안읽음 배지 · **안읽음만 보기 필터**)과 대화창 2단 레이아웃
- 메시지 전송, 내/상대 말풍선 구분, 오전·오후 시간 표기
- 매물 상세의 '채팅하기' → **방 자동 생성**(이미 있으면 기존 방 재사용)
- **거래완료 → 매너 평가 → 채팅방 나가기** 플로우를 모달로 단계별 안내
- 목록 최상단 **AI 챗봇**(추천 질문 기반 UI 목업)

### 동네 인증

- 주소를 검색해 지도에 핀과 **1.5km 인증 반경**을 표시
- 브라우저 GPS로 받은 현재 위치와의 거리를 **Haversine 공식**으로 계산
- 반경 안에 있을 때만 인증 버튼이 활성화되고, 벗어나면 남은 거리를 안내

- `css/common.css`의 `:root`에 컬러 토큰을 정의해 팀원 간 색상 값을 통일했습니다.
- 반응형 브레이크포인트를 **1024px / 768px**로 통일해 페이지마다 어긋나지 않게 맞췄습니다.

## 🤝 협업 방식

**브랜치 전략**

```
main ← develop ← 기능 브랜치 (home / trade / chat / location …)
```

기능 브랜치에서 작업 후 `develop`으로 **Pull Request → 리뷰 → 머지**, 안정화된 시점에 `main`으로 반영했습니다.

**커밋 컨벤션**

| 타입       | 용도                             |
| :--------- | :------------------------------- |
| `feat`     | 새로운 기능 추가                 |
| `fix`      | 버그 수정                        |
| `style`    | CSS · 마크업 등 화면 스타일 변경 |
| `refactor` | 동작 변화 없는 코드 구조 개선    |
| `docs`     | 문서 수정                        |
| `test`     | 테스트 코드/테스트 목적 작업     |
| `chore`    | 기능과 직접 관련 없는 설정       |
| `wip`      | 아직 작업 중인 임시 커밋         |

## 🔧 트러블 슈팅

### 1. 세종특별자치시가 지역 목록에 나오지 않음

- **문제**: 시/도 select에 세종시가 누락되어 해당 지역 사용자가 가입할 수 없었습니다.
- **원인**: 행정구역 코드 API의 `*00000000` 패턴 응답에 세종시가 포함되지 않았습니다.
- **해결**: 목록을 받은 뒤 세종시 항목을 직접 추가하고, 코드 기준으로 재정렬해 순서를 유지했습니다.

### 2. 시/군/구 목록에 선택할 수 없는 상위 지역이 섞임

- **문제**: `경기도 용인시`처럼 하위 구를 가진 지역이 목록에 함께 나와, 선택하면 읍/면/동이 조회되지 않았습니다.
- **원인**: API 응답에 상위 지역과 하위 지역이 같은 depth로 함께 내려왔습니다.
- **해결**: 다른 지역 이름의 앞부분으로 쓰이고 있는 이름을 모아 상위 지역만 걸러냈고, 구 유무에 따라 조회 패턴 자리수(4자리/5자리)를 분기했습니다.

### 3. 한글 검색어 입력 중 Enter가 두 번 처리됨

- **문제**: 한글로 검색할 때 Enter 한 번에 요청이 두 번 발생했습니다.
- **원인**: 한글 IME 조합이 끝나는 시점과 확정 시점에 `keydown`이 각각 발생했습니다.
- **해결**: `e.isComposing`으로 조합 중 Enter를 무시하도록 처리했습니다.

### 4. 검색어를 빠르게 바꾸면 이전 결과가 뒤늦게 화면을 덮음

- **문제**: 연속 검색 시 먼저 보낸 요청의 응답이 나중에 도착해 결과가 뒤바뀌었습니다.
- **원인**: 응답 순서가 요청 순서와 보장되지 않는 비동기 특성 때문이었습니다.
- **해결**: `AbortController`로 새 검색 시 이전 요청을 취소하고, `isLoading` 플래그로 중복 호출을 막았습니다.

### 5. 상세 페이지에서 뒤로 가면 검색 결과가 초기화됨

- **문제**: 검색 결과 → 상세 → 뒤로가기 시 검색어와 페이지가 사라졌습니다.
- **원인**: 상세 페이지가 목록 상태를 알 수 없어 기본 목록으로 이동했습니다.
- **해결**: 진입 경로를 `sessionStorage`에 저장해 원래 위치로 복귀시키고, 글쓰기·수정 페이지에서 되돌아온 경우에는 기존 기록을 덮어쓰지 않도록 예외 처리했습니다.

### 6. 이미지 업로드 요청이 계속 실패함

- **문제**: 사진을 첨부하면 업로드 요청이 실패했습니다.
- **원인**: `FormData` 전송 시 `Content-Type`을 직접 지정해 `boundary` 값이 누락되었습니다.
- **해결**: 헤더에서 `Content-Type`을 제거해 브라우저가 자동으로 생성하도록 했습니다.

### 7. 사진을 여러 번 교체하면 메모리가 계속 점유됨

- **문제**: 미리보기 이미지를 반복 교체할 때 해제되지 않는 객체 URL이 쌓였습니다.
- **원인**: `URL.createObjectURL`로 만든 주소를 해제하지 않았습니다.
- **해결**: 새 사진을 고를 때와 페이지를 떠날 때 `revokeObjectURL`로 이전 주소를 해제했습니다.

### 8. 채팅이 일일 API 호출 한도를 빠르게 소진함

- **문제**: 새 메시지 확인을 위한 주기적 조회가 팀 공용 API 한도를 빠르게 소모했습니다.
- **원인**: 4초 간격 폴링이 방을 열어둔 동안 계속 전체 목록을 조회했습니다.
- **해결**: `after={마지막 메시지 id}`로 **새 메시지만 증분 조회**하도록 바꾸고, 방 전환·페이지 이탈 시 타이머를 정리했습니다. 시연 기간에는 한도 보호를 위해 폴링을 기본 비활성 상태로 두고, 주석 한 줄로 다시 켤 수 있게 남겨두었습니다.
